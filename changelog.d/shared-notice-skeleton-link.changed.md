- Pages that fail to load show one notice: `Couldn't load the thing.` and a reason sentence (`The server answered 503.`, `No response from the server.`, or `The server took too long to answer.` on Anomalies), with a **Retry** button that reads **Retrying…** while it works. A page that already has data keeps it when a refresh fails and shows one line, `Couldn't refresh. Showing data from HH:MM UTC.`, with **Retry**. This covers Executions (the table and the Timeline view), Flows, the Flow page, the Task page, Workers, the Worker page, Registry, Anomalies and the triage panel's run list. A failed next page of Executions or Flows keeps the loaded rows and shows `Couldn't load more.` with **Retry**. See [The frame](docs/ui.md#the-frame).
- The Task and Flow pages say that an item is no longer stored when the server answers 404, with a link back and no **Retry**, and don't retry a 404. A 401 without the built-in login asks for a valid API key.
- Pages that are loading show placeholder blocks in the shape of their content instead of text or blank boxes.
- Links look the same on every page: ink text with a muted underline that turns ink under the pointer. Breadcrumbs stay muted and are underlined only under the pointer. **Show traceback** is a button on the Task page everywhere. The triage panel's title no longer shows a focus box when the panel opens, and still receives focus.
- The command palette says **Searching…** until every source has answered, instead of **No results** while one is still loading.
- A list that loaded empty keeps its empty message under the stale line when a refresh fails (Executions, the Timeline view, the triage panel's run list and the Worker page). A failed next page of Executions or Flows, or a failed **Show more** in the triage panel, keeps the loaded rows and shows `Couldn't load more.` with **Retry**. A poll never asks again for a next page that failed, and a 401 on a next page follows the same rule as any 401.
- With data held, a 404 on the Task page, the Flow page or the triage panel's task view says `This task is no longer stored. Showing data from HH:MM UTC.` (`This flow …` on the Flow page) with no **Retry**, and the page stops polling for it. The Flow page's stale line also covers the inspector's task query. See [The frame](docs/ui.md#the-frame).
