- The Workers page is a table with one row per worker: hostname, status, registered task count, when it started and when it was last seen. An offline worker has a tinted row and a filled status mark. A row opens the new worker page at `/workers/<hostname>`, which lists the worker's registered tasks (each opens Executions for that task), its 25 most recent runs, and its PID, start and last-seen times. A link opens Executions filtered to the worker. Both pages reload every 30 seconds, with or without the live connection. Each reload asks the server to ask Celery for the current worker state; the server skips the inspect within 2 seconds of a successful one and waits longer after failures.
