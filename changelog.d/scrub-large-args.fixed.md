- Capturing task arguments no longer scrubs and serializes a value that is already too big. The capture stops walking after about `max_data_size` nodes, so the time it takes no longer grows with the size of the arguments. The marker for such a value reads `[Truncated: over N bytes > N max]` because the full size is no longer computed. Values that are not obviously too big produce the same output as before, including the exact byte count in the marker.
