- The UI has an Overview page at `/`. Tiles show runs per minute, failures, the failure rate and the workers online, each with the value for the window before it and a sparkline. A chart draws runs per 5 minutes as stacked success, failure and retry bars: click a bar to open its runs, drag across bars to select a span and choose **Open runs**, or switch to the table. **What's wrong** lists failures grouped by exception class. A worker strip and a table of task health by group follow.
- Choosing a bar, a tile, an exception, a worker or a group on the Overview opens a triage panel on the right (a full-screen sheet below 900 px) without moving the page. Rows in the panel open deeper, `Esc` or a crumb goes back one level, and the panel's state is in the `panel` URL parameter, so Back and shared links restore it. A task opened there links to its page and its flow.
- Links to `/` with task-list filters (`/?state=FAILURE`) still open Executions with those filters.
