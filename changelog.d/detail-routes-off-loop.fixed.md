- `GET /api/tasks/{task_id}`, `GET /api/tasks/{task_id}/children` and `GET /api/graphs/{root_id}` no longer hold the event loop while they build and encode their response. For a task with 20,000 direct children the loop was blocked for about 1.7 to 3 seconds (about 90 to 150 ms per 1,000 children); it now does about 3,000 operations between turns, so WebSocket pushes and other requests keep flowing. Response bodies are unchanged.
