- The docs no longer say that Celery never makes two chords name the same callback. Celery 5.6.3 does, for a chord whose body is another chord followed by a task in a chain; the docs now describe how that workflow is drawn with each kind of result backend, including its known limitations: the inner chord's body shows as empty, and with a `celery.chord_unlock` backend the workflow is split into two graphs.
