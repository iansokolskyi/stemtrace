- A worker that you restart under the same nodename, and whose `worker_ready` the server never receives, now reads as stopped when it stops cleanly. Before, the server kept the old process listed as live, so the nodename stayed online in the Workers page and kept the `no_workers_online` alert off for up to 30 minutes after the stop. The server now treats a `worker_shutdown` for a process it doesn't list as the end of the nodename's listed process, when the shutdown is stamped at or after that process's registration. A shutdown stamped earlier is a late stop of an older process and leaves the listed one alone.
