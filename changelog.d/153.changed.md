- **Behavior change:** when a chain step fails, stemtrace now publishes `FAILURE` for each step after it, which Celery never runs or reports. A failed chain used to show only its steps up to the failure; it now shows its steps up to the first group or chord in it, the unrun ones failed with the same exception and no worker. A chord whose header is a chain now shows the header failed when an earlier step of that chain fails. Workers publish these events, so upgrade the workers to see them.
