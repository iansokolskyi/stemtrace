- The Registry page is a table with one row per task name: name, group, status, runs in the last 6 hours, failure rate, p50 and p95 runtime, and when it last ran. The stats come from `GET /api/stats/tasks`; the registry and the stats refresh together every 30 seconds, so a row never mixes two moments. If the stats request fails, the table still shows with empty stats cells. A task no worker registers has a tinted row, a filled status mark and a sentence that explains it; a task registered but never run says which workers register it. A row opens Executions filtered to that exact name. A search box filters by name, group or status in the browser. The status dropdown and the expandable cards (signature, docstring, module) are gone. The page still asks Celery for the current worker state, and the sidebar "not registered" count still reads the stored state.
