- The UI uses Inter and JetBrains Mono, both bundled with the app, instead of Overpass, with lighter weights: body text is 400, labels and table heads are 500, and titles are 600. Success is a calmer green (`#30A46C`) and failure a cleaner red (`#E5484D`) in both themes, so dark mode no longer shows success in teal. Table column headers sit on a tinted band between two rules. The Overview sub-headings show a count beside them.
