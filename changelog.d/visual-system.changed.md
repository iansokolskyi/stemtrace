- The UI uses Inter and JetBrains Mono, both bundled with the app, instead of Overpass, with lighter weights: body text is 400, labels and table heads are 500, and titles are 600. Success is a calmer green (`#30A46C`) and failure a cleaner red (`#E5484D`) in both themes, so dark mode no longer shows success in teal. Bars and blocks for successful runs in the runs chart, the flow diagram, the flow timeline and the task timing bar are a light green tint in light mode and a deep green tint in dark mode, edged in a darker green (a lighter one in dark mode), so they stay distinct from the failure red for people with red-green colour blindness. Table column headers sit on a tinted band between two rules. The Overview sub-headings show a count beside them.
