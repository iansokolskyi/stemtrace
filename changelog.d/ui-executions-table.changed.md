- The Executions page is now a dense table with state, task, group, worker, queue, queue wait, runtime and last update. It loads 200 tasks at a time and draws only the rows on screen, so a long list stays fast. A column appears only when the first page of results has a value for it. A Compact/Comfortable switch sets the row height and is remembered in your browser. While your pointer is over the table, or it is scrolled down, the rows stay where they are: updates show in place and tasks that would be inserted above are counted in a "N new" button.
