- `GET /api/tasks` and `GET /api/graphs` no longer hold the event loop while they scan a large store. With 30,000 runs the default `GET /api/tasks?limit=100` did 151,384 profile events between two loop turns, and `GET /api/graphs?limit=100` did 808,804; each now does at most about 27,700. Above 1,000 stored nodes the scan runs in a worker thread, and a smaller store scans inline as before. Responses are unchanged.
