- A healthy idle worker no longer reads as offline after one lost `inspect` reply. The `no_workers_online` item needs two consecutive unanswered `stats()` calls, completed at least 2 seconds apart, and an answer or an event from the worker starts the count over. After a first unanswered call the server runs one confirming `inspect` when the 2-second interval ends, so a killed fleet still gives the item about one interval later, without a second request. Two misses in a row still read as silent, for example behind a degraded broker link.
