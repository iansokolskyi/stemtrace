- Task events carry `chord_body_first_id`: the ID of the first task of a chord's body, on the events of the chord's header tasks, when the body is a task or a chain that starts with a task. The server uses it to tell a chord's callback from the last task of a chain body, which Celery stamps with the same group ID. A server from before the field ignores it, so you can upgrade the server and the workers in either order; chords whose workers don't send it draw fewer callbacks (see [Graphs: chord callbacks](https://github.com/iansokolskyi/stemtrace/blob/main/docs/graphs.md#chord-callbacks)).
