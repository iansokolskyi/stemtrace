- Each `flow` object of `GET /api/graphs` now has `member_count` and `member_name`. For a GROUP or CHORD root, they give the number of members seen so far and the last segment of the task name that ends every member (the name resolved from task arguments when `node_alias_from_arguments` is set; `null` when the names differ, the segment is empty, or no member exists). Both are `null` for a TASK root.
