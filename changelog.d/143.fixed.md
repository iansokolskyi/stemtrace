- API: `GET /api/groups` and the task registry work out the group of every task name in a worker thread instead of on the event loop, where it held up every other request while it ran (about 80 ms with 7,000 distinct names and automatic groups, more with many group rules).
- API: every `GET` route under `/api` also answers `HEAD` (headers, no body), authenticated like `GET`. `HEAD` used to get `405`. Other wrong methods get `405` with `Allow: GET, HEAD` once past the login check.
