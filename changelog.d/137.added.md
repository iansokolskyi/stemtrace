- A worker that ends without Celery's `worker_shutdown` (a prefork worker stopped with SIGQUIT, or any idle worker stopped with SIGQUIT) now publishes a `worker_terminating` event, and the server marks it offline at once; such a worker used to stay online until the 3-minute stale check (longer on a server that receives no events). With a task running, the threads and gevent pools and a SIGQUIT during a warm stop end with `worker_shutdown`, and a solo worker keeps running; see "Workers and registry tabs" in `docs/features.md`. Upgrade the server before the workers: an older server drops this event with a warning.
