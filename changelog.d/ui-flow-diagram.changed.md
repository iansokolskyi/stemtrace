- The Flow page draws a flow as a track diagram, left to right: each task is a block lit by its state, a group or chord is a box with its members on parallel tracks, and a chord callback that did not run is a dashed box that says why. A box with more than 12 members shows the first three, every failed one and a "+N more" block that expands. Choose a node with a click, Enter or Space to see it in the inspector, which links to the task page. **Jump to failure** chooses and centres the first failed task, and the zoom buttons step from Fit to 140%. A task that a chord callback started is now drawn when the chord body is a chain. You can no longer drag nodes or zoom with the mouse wheel.
